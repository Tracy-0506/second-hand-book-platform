# 微信小程序版本

这是浏览器原型对应的微信小程序项目骨架，使用微信开发者工具导入 `wechat-miniprogram` 文件夹即可查看。

当前使用本地缓存和模拟能力：

- 重庆邮电大学、重庆工商大学学校市场
- 发布、浏览和搜索书籍
- 模拟手机号登录
- 模拟支付和15%平台服务费计算
- 线下面交、确认收货、面交前退款
- 演示管理员后台

## 导入方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 目录选择本文件夹中的 `wechat-miniprogram`。
4. AppID 暂时选择“测试号”或使用你自己的 AppID。

正式上线还需要接入：微信云开发数据库、真实手机号验证、图片上传、管理员身份校验、微信支付分账和退款接口。
